# Examples

Sample agent registration configs for use with `agtm upload --config` or as a reference for the Python `aa.add()` API.

| File | Format | Usage |
|------|--------|-------|
| [agent.json](agent.json) | JSON | `agtm upload --config ./examples/agent.json` |
| [agent.yaml](agent.yaml) | YAML | `agtm upload --config ./examples/agent.yaml` |

Get your access key at [Marketplace API Keys](https://www.deepnlp.org/workspace/keys).
